  过渡时间: 3秒（可配置）

使用说明：

【启动系统】
  cd ~/gello_software
  ./run_fr3_with_recorder.sh

【录制】
  1. 点击 "🔴 Start Recording"
  2. 使用GELLO操作机械臂
  3. 点击 "⏹️ Stop Recording"

【重放】
  1. 选择录制文件
  2. 点击 "▶️ Start Replay"
  3. 观察3个阶段：
     - Phase 1: 过渡到起始位置（3秒）
     - Phase 2: 重放轨迹（录制时长）
     - Phase 3: 返回GELLO位置（3秒）
  4. 完成后可继续用GELLO控制

【测试平滑过渡】
  cd ~/gello_software/franka_recorder

  # 启动节点
  python3 recorder_node.py &
  python3 replay_node.py &

  # 运行测试
  python3 test_smooth_transition.py
