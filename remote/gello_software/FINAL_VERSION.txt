🚀 使用方法：

【启动系统】
  cd ~/gello_software
  ./run_fr3_with_recorder.sh

【录制轨迹】
  1. 点击 "🔴 Start Recording"
  2. 用GELLO控制机械臂
  3. 点击 "⏹️ Stop Recording"
  4. 轨迹自动保存

【重放轨迹】（重要！）
  1. ⚠️ 用GELLO手动移动到接近起始位置
  2. 选择录制文件
  3. 点击 "▶️ Start Replay"
  4. 系统自动检查位置：
     - ✅ 位置OK → 开始重放
     - ⚠️ 有警告 → 询问是否继续
     - ❌ 太远 → 拒绝并要求移动
  5. 重放完成

🛡️ 安全特性详解：

【位置检查机制】
  - 计算当前位置与起始位置的最大差异
  - 使用欧氏距离度量
  - 实时监控GELLO和Franka状态

【三级保护】
  级别1 (安全):  差异 < 0.5 rad
    → 绿灯通过，直接重放
    → 提示: "Position OK"

  级别2 (警告):  差异 0.5-1.0 rad
    → 黄灯警告，询问用户
    → 提示: "Warning: Position difference is XXX rad"
    → 选择: "Do you want to continue?"

  级别3 (拒绝):  差异 > 1.0 rad
    → 红灯拒绝，要求移动
    → 提示: "SAFETY: Position difference too large"
    → 操作: 必须用GELLO移动到更近位置

【GUI警告提示】
  - 位置检查失败：错误对话框
  - 位置有警告：确认对话框
  - 位置安全：直接开始

💡 使用技巧：

1. 录制技巧：
   ✓ 记住起始姿态（拍照或记录）
   ✓ 动作不要太快
   ✓ 避免接近关节限位
   ✓ 录制时间适中（3-30秒）

2. 重放技巧：
   ✓ 重放前先对齐位置（最重要！）
   ✓ 不需要完全精确，系统有容差
   ✓ 第一次重放选择慢速轨迹测试
   ✓ 注意系统提示信息

3. 避免红灯：
   ✓ 确保位置差异 < 0.5 rad
   ✓ 重放前用GELLO慢慢移动
   ✓ 不要忽略警告信息
   ✓ 环境清空，无障碍物

🔍 故障排除：

【问题1：仍然亮红灯】
  原因: 位置差异仍然太大，或录制速度太快
  解决:
    - 移动更接近起始位置
    - 录制时动作慢一些
    - 检查安全阈值设置

【问题2：GUI显示位置检查失败】
  原因: 当前位置与起始位置差异 > 1.0 rad
  解决:
    - 用GELLO移动到更接近起始位置
    - 检查是否选择了正确的录制文件

【问题3：没有收到警告就重放了】
  原因: 位置差异很小（< 0.5 rad）
  解决:
    - 这是正常的，表示位置很好
    - 可以安全重放

【问题4：GUI没有弹出】
  解决:
    sudo apt-get install python3-tk
