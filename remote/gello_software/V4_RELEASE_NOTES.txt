💡 为什么 v4.0 不会卡死？

【v3.0 的问题】

  简单三次插值：
    position(t) = start + (end - start) * (3t² - 2t³)

  问题：
    - 不考虑速度限制 → 可能超速
    - 不考虑加速度限制 → 超过机械臂能力
    - 阻抗控制器跟不上 → 卡死

【v4.0 的优势】

  MotionGenerator 算法：
    - 梯形速度曲线
    - 严格遵守 dq_max 和 ddq_max
    - 平滑加速和减速
    - 与 FR3 启动完全相同
    - Franka 官方验证

  数学保证：
    max_velocity = 0.4 rad/s (joint 1-4)
    max_accel = 1.0 rad/s²
    → 远低于机械臂物理限制
    → 绝对安全！

🔍 代码对比：

【v3.0 - 简单插值】

  def interpolate_positions(self, start_pos, end_pos, t):
      t_smooth = 3 * t**2 - 2 * t**3
      return start + (end - start) * t_smooth

  # 固定时长 5 秒
  num_steps = int(5.0 * 30)

【v4.0 - MotionGenerator】

  # 创建 motion generator
  motion_gen = MotionGenerator(
      speed_factor=0.2,
      q_start=current_position,
      q_goal=target_position
  )

  # 自动计算时长
  duration = motion_gen.get_trajectory_duration()

  # 获取每个时刻的期望位置
  while True:
      q_desired, finished = motion_gen.get_desired_joint_positions(elapsed)
      if finished:
          break
