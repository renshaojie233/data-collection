命令速查：

    启动系统：
    $ cd ~/gello_software
    $ ./run_fr3_with_recorder.sh

    运行测试：
    $ cd ~/gello_software/franka_recorder
    $ python3 test_auto_alignment.py

    查看录制文件：
    $ ls ~/gello_software/franka_recordings/

    命令行重放：
    $ ros2 service call /franka_replay/start_stop \
      std_srvs/srv/SetBool "{data: true}"

关键文件路径：

    录制节点：
    ~/gello_software/franka_recorder/recorder_node.py

    重放节点：
    ~/gello_software/franka_recorder/replay_node.py

    GUI界面：
    ~/gello_software/franka_recorder/control_gui.py

    录制文件：
    ~/gello_software/franka_recordings/*.pkl

重要参数：

    对齐时长：self.alignment_duration = 5.0  # 秒
    采样频率：self.alignment_rate = 30       # Hz
    最小阈值：min_alignment_threshold = 0.01 # rad
