# ⚠️ 安全修复 - 防止机械臂抽动和红灯问题

## 🔧 问题说明

**原问题**：重放时机械臂会瞬间抽动，然后停止并亮红灯。

**根本原因**：
- 当前位置与录制起始位置差距太大
- 直接发布录制位置导致位置跳变过大
- Franka机械臂触发安全保护机制（红灯）

## ✅ 修复方案

### 1. 位置安全检查

系统现在会在重放前检查位置差异：

```
检查规则：
- 差异 < 0.5 弧度 (28.6°)  ✅ 安全，直接重放
- 差异 0.5-1.0 弧度        ⚠️ 警告，询问是否继续
- 差异 > 1.0 弧度 (57.3°)  ❌ 拒绝重放，要求先移动
```

### 2. 使用方式

**重要**：在重放前，必须：

1. **使用GELLO手动移动机械臂**到接近录制起始位置
2. 点击重放按钮
3. 系统自动检查位置
4. 如果通过检查，开始重放

## 📋 使用步骤

### 录制

1. 点击 "🔴 Start Recording"
2. 用GELLO操作机械臂
3. 点击 "⏹️ Stop Recording"

### 重放（重要！）

1. **先用GELLO移动**到接近录制起始位置
   - 不需要完全精确，但要在0.5弧度以内
   - 系统会自动检查并提示

2. 选择录制文件

3. 点击 "▶️ Start Replay"

4. 系统检查位置：
   - ✅ 如果位置OK → 开始重放
   - ⚠️ 如果有警告 → 询问是否继续
   - ❌ 如果太远 → 拒绝重放，要求移动

5. 重放完成后，机械臂停在结束位置

## 🛡️ 安全特性

### 自动位置检查
- 计算当前位置与起始位置的最大差异
- 超过安全阈值自动拒绝
- 防止突然的大幅度运动

### 警告系统
```
差异 < 0.5 rad:  ✅ 安全
             提示: "Position OK: difference is 0.123 rad"

差异 0.5-1.0 rad: ⚠️ 警告
                提示: "Warning: Position difference is 0.678 rad.
                      Recommended to move closer, but replay is allowed."
                询问: "Do you want to continue with replay?"

差异 > 1.0 rad:  ❌ 错误
               提示: "SAFETY: Position difference too large (1.234 rad).
                     Please move GELLO closer to start position first."
               拒绝重放
```

### 可配置的安全参数

在 `replay_node.py` 中可以调整：

```python
# 警告阈值（弧度）
self.max_position_diff_warning = 0.5  # 约28.6度

# 错误阈值（弧度）
self.max_position_diff_error = 1.0    # 约57.3度
```

## 🎯 为什么会有红灯问题？

**Franka FR3安全机制**：
1. 监控关节速度和加速度
2. 检测碰撞和异常力
3. 当检测到危险情况时，立即停止并亮红灯

**触发原因**：
- 位置跳变太大 → 机械臂尝试快速移动
- 超过安全速度/加速度限制
- 触发保护性停止

**解决方法**：
- 确保起始位置接近 → 避免大幅度运动
- 使用GELLO手动移动到附近 → 平滑过渡
- 系统检查位置差异 → 预防问题

## 💡 使用建议

### 最佳实践

1. **录制时记住起始姿态**
   - 录制前注意机械臂的起始位置
   - 或者拍照记录

2. **重放前先对齐**
   - 用GELLO移动到接近起始位置
   - 不需要完全精确，系统有容差

3. **观察安全距离**
   - 如果看到警告，建议再调整一下
   - 如果被拒绝，必须移动更近

4. **渐进式重放**
   - 第一次重放在安全环境中测试
   - 确认轨迹安全后再实际使用

### 避免红灯的技巧

1. ✅ 录制和重放在相似的起始位置
2. ✅ 重放前用GELLO慢慢移动到接近位置
3. ✅ 注意系统的位置检查提示
4. ❌ 不要在完全不同的位置尝试重放
5. ❌ 不要忽略警告信息

## 🆘 如果还是亮红灯怎么办？

1. **检查机械臂模式**
   - 确保FR3处于正确的控制模式
   - 检查急停按钮是否释放

2. **降低速度**
   - 如果仍有问题，可能录制的速度太快
   - 录制时动作慢一些

3. **检查工作空间**
   - 确保没有碰到限位
   - 检查周围无障碍物

4. **查看日志**
   ```bash
   ros2 topic echo /franka/errors
   ```

5. **重启系统**
   - 停止所有节点
   - 重启FR3
   - 重新运行程序

## 📝 技术细节

### 位置差异计算

```python
def calculate_position_difference(pos1, pos2):
    """计算两个关节状态的最大位置差异"""
    diff = abs(pos1 - pos2)
    return max(diff)  # 返回最大的关节差异
```

### 安全检查流程

```
开始重放请求
    ↓
读取当前位置
    ↓
读取录制起始位置
    ↓
计算最大差异
    ↓
差异 > 1.0 rad? ─Yes→ 拒绝重放
    ↓ No
差异 > 0.5 rad? ─Yes→ 警告用户
    ↓ No
开始重放
```
