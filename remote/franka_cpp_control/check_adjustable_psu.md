# 可调电源诊断指南

你的设置：24V, 3.5A - **理论上完全足够！**

## 🔍 可调电源常见问题

### 1. CV vs CC 模式

可调电源有两种工作模式：
- **CV (Constant Voltage)** - 恒压模式 ✓ 应该是这个
- **CC (Constant Current)** - 恒流模式

**检查：**
- 电源显示屏上应该显示 "CV" 而不是 "CC"
- 如果显示 "CC"，说明电流被限制了
- 电压应该稳定在24V，电流应该随负载变化

### 2. 电流限制设置

有些可调电源有**软启动**或**过流保护**功能：

**检查：**
- 是否有 "OCP" (过流保护) 设置？
- 是否设置了电流限制低于3.5A？
- 尝试将电流限制提高到 **5A** 试试

### 3. 输出是否真的开启

**检查：**
- 电源上的 "OUTPUT" 开关是否打开？
- 有些电源有远程控制功能，是否被禁用？
- LED指示灯是否显示输出开启？

### 4. 连接问题

**检查：**
- 电源端子连接是否牢固？
- 电线是否太细？（建议至少18AWG）
- 正负极是否接对？

## 🧪 测试步骤

### 步骤1：用万用表测量

```
1. 断开夹爪连接
2. 测量电源输出端：
   - 应该显示 24V±0.5V

3. 连接夹爪后再测量：
   - 电压不应下降超过1V
   - 如果电压掉到 < 22V → 连接问题或电源问题
```

### 步骤2：观察电源显示

启动夹爪时观察电源：
```
正常情况：
- 电压：24V (稳定)
- 电流：瞬间跳到 1-3A，然后下降
- 模式：CV (恒压)

异常情况：
- 模式变成 CC → 触发电流限制
- 电压下降 → 电源带载能力不足
- 电流一直是 0 → 没有连接或开关未开
```

### 步骤3：尝试不同设置

```
尝试1：提高电流限制
  设置：24V, 5A

尝试2：降低电压看是否有响应
  设置：20V, 5A（临时测试）

尝试3：检查输出使能
  确保OUTPUT按钮已按下
```

## 💡 可能的原因

### 原因A：电源设置问题（70%可能）

- 电流限制太保守
- 过流保护被触发
- 输出未使能

### 原因B：连接问题（20%可能）

- 接线松动
- 线太细/太长
- 接触不良

### 原因C：寄存器读数不准（10%可能）

- 夹爪的电流寄存器可能不准确
- 但实际电流是足够的
- 可以通过观察夹爪动作判断
