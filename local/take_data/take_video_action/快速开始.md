# 🚀 快速开始

## 一、启动系统

### 方式1: 双击桌面图标（推荐）
找到并双击桌面上的 **"视频+动作录制"** 图标

### 方式2: 使用命令
打开终端，输入：
```bash
record-video-action
```

## 二、等待初始化

系统会自动初始化：
- ✅ 加载3个RealSense相机
- ✅ 显示实时预览画面
- ✅ 准备数据采集系统

**等待时间**: 约5-10秒

## 三、开始录制

1. 点击 **"▶️ 开始录制"** 按钮

2. 系统自动执行：
   - 连接远程机器人（172.16.1.2）
   - 启动ROS2系统
   - 开始同步录制

3. **录制指示器**:
   - 视频预览左上角出现 🔴 **REC** 标识
   - 录制状态显示：🔴 **正在录制**
   - 时长计时器开始计时

4. **操作机器人**:
   - 使用GELLO设备控制Franka机械臂
   - 视频和动作数据同步记录

## 四、停止录制

点击 **"⏹️ 停止录制"** 按钮

系统自动：
- 保存视频文件（MP4格式）
- 保存动作数据（JSON + HDF5格式）
- 清理远程进程
- 显示保存位置

## 五、查看数据

### 方法1: 通过GUI
查看界面上显示的保存路径

### 方法2: 使用命令
```bash
# 打开数据总目录
record-video-action data

# 只看视频
record-video-action video

# 只看动作数据
record-video-action action
```

### 方法3: 手动浏览
```bash
cd /home/ubuntu/take_data/data

# 视频
ls -lh video/record_001/

# 动作数据
ls -lh action/record_001/
```

## 六、继续录制

- 再次点击 **"▶️ 开始录制"**
- 新数据自动保存为 `record_002`
- 序号自动递增：`record_003`, `record_004`...

## 七、退出系统

### 方式1: 点击退出按钮
点击 **"🚪 退出系统"**

### 方式2: 关闭窗口
直接关闭GUI窗口

### 方式3: Ctrl+C
在终端按 `Ctrl+C`

**所有方式都会自动清理远程进程！**

---

## 🎯 典型工作流程

```
1. 双击桌面图标
   ↓
2. 等待相机初始化（10秒）
   ↓
3. 点击"开始录制"
   ↓
4. 操作GELLO控制机械臂
   ↓
5. 点击"停止录制"
   ↓
6. 查看保存的数据
   ↓
7. 重复步骤3-6进行多次录制
   ↓
8. 点击"退出系统"
```
