║          三相机视频录制系统 - 启动方式说明                 ║
╚══════════════════════════════════════════════════════════╝

您现在有多种方式启动视频录制系统，选择最适合您的方式！

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🖱️  方式1：双击图形化启动器（推荐⭐）

   文件名：启动器.py

   操作步骤：
   1. 在文件管理器中进入 /home/ubuntu/take_data/take_video/
   2. 双击 "启动器.py" 文件
   3. 会弹出一个图形化启动界面
   4. 点击"启动录制程序"按钮

   优点：
   ✓ 图形化界面，操作简单
   ✓ 显示系统状态信息
   ✓ 可以测试相机连接
   ✓ 适合不熟悉命令行的用户

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🖱️  方式2：双击Desktop文件

   文件名：启动录制系统.desktop

   操作步骤：
   1. 在文件管理器中双击 "启动录制系统.desktop"
   2. 如果系统提示信任，选择"信任并启动"
   3. 会自动打开图形化启动器

   优点：
   ✓ 一键启动
   ✓ 可以复制到桌面使用
   ✓ 系统集成，专业外观

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🖱️  方式3：双击Shell脚本启动

   文件名：start_video_recorder.sh

   操作步骤：
   1. 在文件管理器中双击 "start_video_recorder.sh"
   2. 选择"在终端中运行"
   3. 程序会在终端中启动，显示详细信息

   优点：
   ✓ 显示详细的启动信息
   ✓ 可以看到错误提示
   ✓ 适合调试和排查问题

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

💻 方式4：命令行启动

   方法A - 使用run_video_recorder.sh:
   ```
   cd /home/ubuntu/take_data/take_video
   ./run_video_recorder.sh
   ```

   方法B - 手动启动:
   ```
   conda activate take_data
   cd /home/ubuntu/take_data/take_video
   python take_video.py
   ```

   优点：
   ✓ 完全控制
   ✓ 适合远程SSH连接
   ✓ 适合脚本自动化

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 所有启动文件列表:

1. 启动器.py                    # Python图形化启动器（推荐）
2. 启动录制系统.desktop         # Desktop启动图标
3. 三相机录制.desktop           # 备用Desktop图标
4. start_video_recorder.sh      # 详细启动脚本
5. run_video_recorder.sh        # 简洁启动脚本

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🌟 推荐使用方式:

初次使用者：
  → 双击 "启动器.py"（方式1）

日常使用：
  → 将 "启动录制系统.desktop" 复制到桌面，双击启动

调试问题：
  → 双击 "start_video_recorder.sh"（方式3）

远程连接：
  → 使用命令行启动（方式4）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

💡 将图标添加到桌面:

方法1（推荐）:
  cp "/home/ubuntu/take_data/take_video/启动录制系统.desktop" ~/桌面/

方法2:
  在文件管理器中，将 "启动录制系统.desktop" 拖到桌面

方法3:
  右键点击 "启动录制系统.desktop" → 发送到 → 桌面

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️  注意事项:

1. 如果双击.desktop文件无反应：
   - 右键点击文件 → 属性 → 权限 → 勾选"允许作为程序执行"
   - 或运行: chmod +x 文件名.desktop

2. 如果双击.py文件直接用编辑器打开：
   - 右键点击 → 打开方式 → 选择Python 3

3. 所有启动方式最终都会：
   ✓ 激活conda环境 take_data
   ✓ 打开GUI控制界面（中文）
   ✓ 打开三相机预览窗口
