# 三相机视频录制系统 - 启动方法

## 🎯 推荐启动方式

### ⭐ 方法1：双击 Shell 脚本（最简单）

```
双击文件：启动录制.sh
```

**如果双击没反应：**
1. 右键点击 `启动录制.sh`
2. 选择 "运行为程序" 或 "在终端中运行"

**或者设置权限：**
1. 右键点击 `启动录制.sh` → 属性
2. 切换到 "权限" 标签
3. 勾选 "允许作为程序执行文件"
4. 关闭后再双击

---

### 🖥️ 方法2：从桌面启动

```
双击桌面上的 "启动录制系统.desktop" 图标
```

**如果图标无法启动：**
1. 右键点击图标 → 允许启动
2. 或右键 → 属性 → 权限 → 允许作为程序执行

---

### 💻 方法3：命令行启动

打开终端，输入：

```bash
cd /home/ubuntu/take_data/take_video
./启动录制.sh
```

或者：

```bash
cd /home/ubuntu/take_data/take_video
conda activate take_data
python take_video.py
```

---

## 📋 启动后的界面

### 界面1：图形化启动器
- 显示系统状态（环境、路径、相机）
- 点击 **"启动录制程序"** 按钮
- 可以点击 **"测试相机连接"** 测试相机

### 界面2：三相机预览窗口
- 显示三个相机的实时画面（水平拼接）
- 录制时显示红色 "REC" 标识
- 按 'q' 键可关闭预览窗口

### 界面3：录制控制界面（中文GUI）
- **"开始录制"** - 开始录制三个相机
- **"停止录制"** - 停止录制并保存
- 实时显示录制时长
- **"退出程序"** - 退出系统

## ⚠️ 常见问题

### Q: 双击.sh文件用文本编辑器打开了？
**A:** 右键点击 → 选择 "运行为程序" 而不是 "打开"

### Q: 双击.py文件用文本编辑器打开了？
**A:** 使用 `启动录制.sh` 代替，不要双击.py文件

### Q: 桌面图标无法启动？
**A:** 右键点击图标 → 允许启动 / Trust and Launch

### Q: 提示找不到conda？
**A:** 在终端中运行：
```bash
source /home/ubuntu/anaconda3/bin/activate take_data
cd /home/ubuntu/take_data/take_video
python take_video.py
```

### Q: 提示相机连接失败？
**A:**
1. 检查USB连接
2. 重新插拔相机
3. 运行测试：`python test_cameras.py`
